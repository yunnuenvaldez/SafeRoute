# SafeRoute

A web application focused on safer mobility, built with Vue 3, TypeScript, and Supabase.

## Technologies

- **Frontend:** Vue 3, TypeScript, Vite
- **Database and backend services:** Supabase
- **Payments:** Stripe and Mercado Pago
- **Additional tools:** Node.js, Express, Git, and GitHub

## Features

- User interface built with Vue 3 and TypeScript.
- Supabase client integration.
- Backend endpoints for creating Stripe and Mercado Pago payment sessions.
- Premium access payment flow under development.

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd SafeRoute
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Configure your environment variables in a local `.env` file.

5. Start the frontend:

   ```bash
   npm run dev
   ```

6. Start the backend separately using your configured Node.js environment.

## Environment Variables

Keep secret keys in your local `.env` file. Never commit this file or publish Stripe secret keys or Mercado Pago access tokens.
